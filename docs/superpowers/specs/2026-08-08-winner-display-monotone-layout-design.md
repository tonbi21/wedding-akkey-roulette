# 当選表示・モノトーンレイアウト 仕様

## 目的

Stop後に確定したアクキー画像を表示し、既存のWinner演出を各ラウンドで表示する。画面全体はモノトーンに統一し、アクキー画像と操作ボタンを縦方向中央に配置する。

## 動作

- Stop時に当選IDを`currentKeychainId`へ設定し、winner状態へ遷移する。
- winner状態では確定したアクキー画像と既存の`WinnerOverlay`を表示する。
- NEXTで次ラウンドへ進み、3ラウンドそれぞれでWinnerOverlayを表示する。
- WinnerOverlayの現行演出（confetti、flash、shake、sparkle）は変更しない。
- 当選者は中央モーダルで表示する。閉じるボタン、背景クリック、ESCで閉じられるようにする。
- 既存の当選ID保存と重複防止を維持する。

## ビジュアル

- 紫、黄色、赤などのアクセントカラーを廃止し、黒・白・グレーへ統一する。
- アクキー画像は画面中央に配置する。
- ENTER、START、STOP、NEXTはアクキー画像の下に縦方向の操作領域として配置する。
- デスクトップでも画像とボタンの横並びレイアウトは使用しない。

## 対象範囲

- STOP時のReducer状態
- winner状態の画像・WinnerOverlay表示
- 当選者モーダルの表示方式
- グローバル配色とレスポンシブレイアウト
- 状態・画面テスト

## 対象外

- WinnerOverlay内部の演出表現
- 抽選対象選定・重複防止ロジック
- 音声ファイルそのもの
